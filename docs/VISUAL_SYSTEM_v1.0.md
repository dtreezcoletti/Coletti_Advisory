# Coletti & Co. Visual System v1.0

Status: CONTROLLED
Effective date: 2026-09-06

## Positioning

The Coletti & Co. interface should read as:

- boutique professional services;
- restrained luxury;
- private-client discretion;
- editorial clarity;
- institutional competence;
- high trust rather than high-tech spectacle.

It should **not** read as generic fintech, a retail bank dashboard, consumer productivity software, crypto, gaming, or a neon AI product.

## Design law

**Expensive should come from restraint, typography, spacing, materials and confidence — not decorative gold, oversized gradients or visual noise.**

## Palette

- Ink: `#171715`
- Soft ink: `#2A2926`
- Warm paper: `#F6F3ED`
- Card: `#FFFDF9`
- Deep paper: `#EFEAE3`
- Fine rule: `#DCD5CA`
- Aged brass: `#94703B`
- Deep brass: `#75562D`
- Reserved green: `#486153`

Brass is an accent, not a fill color for large surfaces.

## Typography

- Display/headings: restrained old-style serif (`Iowan Old Style`, `Palatino`, Georgia fallback).
- Interface/body: clean modern sans serif.
- Headings should be lighter-weight, editorial and spacious.
- Micro-labels may use small uppercase tracking.
- Avoid fake luxury through excessive italics, scripts or decorative type.

## Geometry

- Primary cards/panels: 3–6 px radius.
- Fine 1 px rules instead of floating rounded containers everywhere.
- Shadows should be nearly imperceptible.
- Pills reserved for true status/identity chips.
- Mobile remains touch-friendly without becoming a bubble-heavy consumer app.

## Role experiences

### Client

Brightest and most service-oriented surface. It should feel private, calm and managed: clear status, next actions, requests, secure upload, progress and finished reports. Technical controls and internal reasoning remain absent.

### Employee

Same brand system with denser operational information. Evidence, review and analysis views prioritize clarity and speed without becoming visually industrial.

### Owner

Same visual language, with stronger charcoal treatment for the owner/system banner and access to System Lab/administration. Power should be communicated through information hierarchy, not a radically different theme.

## Components

- Sidebar selected state: charcoal field with a thin brass edge, not a gold gradient.
- Primary action: charcoal button.
- Status success: muted institutional green.
- Hero: editorial service-firm composition, not a marketing billboard.
- KPI cards: fine border, warm-white card, serif number, restrained icon treatment.
- Tables: clear rules and whitespace; avoid heavy colored rows unless state requires it.
- Alerts: use color only to communicate actual state/risk.

## Motion and decoration

- No decorative animation is required for v1.
- Avoid parallax, glowing borders, excessive hover movement or dashboard gimmicks.
- Decorative geometry should be subtle and architectural.

## Accessibility

Luxury styling never overrides usability. Maintain readable contrast, visible focus states, sufficiently large mobile targets, plain-language labels and explicit status text in addition to color.

## Change control

A future visual change should be accepted only when it makes the interface more:

- composed;
- legible;
- trustworthy;
- premium;
- consistent across client, employee and owner roles.

“More modern” is not, by itself, a reason to move toward generic SaaS aesthetics.
